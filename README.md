# 🎓 زبان‌یار | Zabanyar

**پلتفرم آموزش زبان انگلیسی مبتنی بر هوش مصنوعی، مخصوص فارسی‌زبانان**

پلتفرمی SaaS و Serverless که سطح زبان‌آموز را می‌سنجد، الگوی اشتباهات تکرارشونده‌اش را کشف می‌کند و برای هر ضعف، درس و تمرین اختصاصی می‌سازد. تمام رابط کاربری و توضیحات آموزشی به **فارسی روان و راست‌چین**.

</div>

```
Next.js 16  ·  TypeScript  ·  Tailwind CSS 4  ·  Supabase  ·  Vercel
```

## ✨ قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| 🎯 **آزمون تعیین سطح تطبیقی** | ۱۴ سؤال از بانک ۳۶ سؤالی کالیبره‌شده. با هر پاسخ درست سخت‌تر و با هر اشتباه ساده‌تر می‌شود. نمره‌دهی وزن‌دار بر اساس سختی. خروجی: سطح CEFR از A1 تا C2 + امتیاز تفکیکی هر مهارت. |
| 🧠 **مربی با حافظه بلندمدت** | مربی، سطح، اشتباهات، کلمات دشوار، علاقه‌مندی‌ها و سرعت یادگیری شما را به خاطر می‌سپارد و هر پاسخ را بر همان اساس می‌سازد. |
| 🔍 **هوش تحلیل خطا** | هر اشتباه با یک برچسب استاندارد (مثل `past_simple`) ثبت و شمارش می‌شود. وقتی الگویی تکرار شود، سیستم یک درس اختصاصی برای رفع همان ضعف تولید می‌کند. |
| 📚 **درس شخصی‌سازی‌شده** | درس بر اساس ضعیف‌ترین مهارت، سطح فعلی و علاقه‌مندی‌های شما ساخته می‌شود — نه محتوای آماده یکسان برای همه. |
| 🔁 **مرور هوشمند لغات** | الگوریتم تکرار فاصله‌دار **SM-2**: هر لغت دقیقاً در آستانه فراموشی نمایش داده می‌شود. |
| ✍️ **تصحیح خودکار** | نمره، متن اصلاح‌شده، فهرست اشتباهات و توضیح فارسی هرکدام — در چند ثانیه. |
| 🏅 **نشان‌های دستاورد** | ۱۷ نشان در چهار سطح برنز تا پلاتین — از «اولین قدم» تا «هزار لغت» و «بدون خطا». پس از هر فعالیت یادگیری خودکار بررسی و اعطا می‌شوند. |
| 🏆 **جدول امتیاز** | رقابت دوستانه هفتگی و کل‌زمان بر پایه XP. **کاملاً اختیاری (opt-in)** — تا وقتی خودتان فعال نکنید در هیچ فهرست عمومی دیده نمی‌شوید و ایمیل‌تان هرگز نمایش داده نمی‌شود. |
| 🔥 **استریک روزانه** | روزهای پیاپی تمرین به‌طور خودکار از تاریخچه یادگیری محاسبه می‌شود. |
| 💬 **مکالمه با نقش‌آفرینی** | سناریوهای واقعی: کافی‌شاپ، هتل، مصاحبه شغلی، مطب دکتر، فرودگاه. |
| 📈 **گزارش پیشرفت** | نمودار فعالیت ۳۰ روزه، نقشه راداری مهارت‌ها و تحلیل الگوهای خطا. |
| 🛡️ **پنل مدیریت** | آمار سامانه و مدیریت کاربران، محافظت‌شده با RLS. |

## 🗄️ دیتابیس

**۱۴ جدول، همه با Row Level Security فعال:**

| جدول | نقش |
|---|---|
| `profiles` | پروفایل کاربر، نقش، سطح، هدف، علاقه‌مندی، استریک |
| `skill_levels` | امتیاز و سطح هر یک از ۶ مهارت |
| `placement_tests` | آزمون تعیین سطح با سؤال و پاسخ‌های ذخیره‌شده |
| `lessons` | درس‌ها (اختصاصی کاربر یا عمومی) |
| `exercises` | تمرین‌های هر درس |
| `assignments` | تکالیف واگذارشده |
| `submissions` | پاسخ‌های ارسالی + بازخورد هوشمند |
| `mistakes_memory` | 🔍 حافظه اشتباهات — قلب تحلیل خطا |
| `vocabulary_memory` | 🔁 حافظه لغات با پارامترهای SM-2 |
| `conversations` / `messages` | مکالمات مربی + تصحیح‌ها |
| `learning_history` | رویدادهای یادگیری (XP، زمان، دقت) |
| `progress_reports` | گزارش‌های دوره‌ای |
| `ai_memory` | 🧠 حافظه بلندمدت مربی |
| `badges` | کاتالوگ نشان‌های دستاورد |
| `user_badges` | 🏅 نشان‌های کسب‌شده (درج فقط سمت سرور) |
| `leaderboard_view` | 🏆 نمای جدول امتیاز — فقط کاربران opt-in |

### قوانین دسترسی

| نقش | دسترسی |
|---|---|
| **زبان‌آموز** | فقط داده‌های خودش |
| **مدرس** | داده‌های خودش + دانش‌آموزان منتسب به او |
| **مدیر** | دسترسی کامل |
| **مهمان** | هیچ داده‌ای |

> ارتقای نقش توسط کاربر با یک تریگر محافظ (`guard_profile_update`) مسدود می‌شود؛ ستون‌های `role`، `subscription` و `teacher_id` برای کاربر عادی تغییرناپذیرند.

**باکت‌های استوریج:** `avatars` (عمومی) · `speech` (خصوصی) · `submissions` (خصوصی) — دسترسی محدود به پوشهٔ خود کاربر.

## 🤖 موتور هوش مصنوعی

معماری دو لایه با **fallback خودکار**:

1. **سرویس بیرونی** — هر endpoint سازگار با OpenAI (اختیاری).
2. **موتور محلی قاعده‌مند** — همیشه فعال، بدون نیاز به کلید یا هزینه.

> ⚠️ **مهم:** اگر `OPENAI_API_KEY` تنظیم نشود، اپلیکیشن **کاملاً کار می‌کند** و از موتور محلی استفاده می‌کند. هیچ قابلیتی از کار نمی‌افتد. اگر سرویس بیرونی هم به هر دلیلی خطا بدهد، به‌صورت خودکار روی موتور محلی برمی‌گردد.

**موتور محلی شامل:** ۲۱ قاعده گرامری متمرکز بر خطاهای رایج فارسی‌زبانان · تولیدکننده درس با ۴ قالب کامل · مربی تحلیل‌گر · موتور مکالمه · پیاده‌سازی SM-2 · نمره‌دهی وزن‌دار CEFR.

## 🚀 راه‌اندازی

### پیش‌نیاز
Node.js 20+ · یک پروژه Supabase · حساب Vercel

</div>

```bash
git clone https://github.com/yaserrezai-byte/zabanyar.git
cd zabanyar
npm install
cp .env.example .env.local     # مقادیر را پر کنید
npm run dev
```

### متغیرهای محیطی

</div>

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_REF.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...      # فقط سمت سرور
```
